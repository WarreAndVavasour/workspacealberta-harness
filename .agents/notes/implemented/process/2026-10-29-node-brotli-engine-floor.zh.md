# Agent Note: 拒绝缺少 CVE-2026-111497 Brotli 修复的 Node 构建

Status: implemented

[English](2026-10-29-node-brotli-engine-floor.md) | 中文

## 问题

CVE-2026-111497 是 Node.js 捆绑的 Brotli 解码器中的越界写，已有针对未修补镜像的利用报告。修复版本是 22.23.4、24.22.1 与 26.12.1。Node.js 20、23 与 25 已结束生命周期，不会收到修复。若支持范围接受更早的 22、24 或 26 构建，或通过开放的 `>=24` 项接受 Node 25，部署就会跑在有漏洞的运行时上。

## 决策

根 `engines.node` 为 `^22.23.4 || ^24.22.1 || >=26.12.1`。`^22.23.4` 表示 `>=22.23.4 <23.0.0`。`^24.22.1` 表示 `>=24.22.1 <25.0.0`，从而排除已结束生命周期的 Node 25。`>=26.12.1` 排除 Node 26.0.0 至 26.12.0，并仍然接受更高的主版本。已发布的 `@workspacealberta/node-addon-landlock-run` 入口包与平台包声明同一范围。

`node-compat` 矩阵固定 `22.23.4` 与 `24.22.1`，并让 `26` 保持浮动，以便当前的 26 发布仍在测试中。主要任务继续浮动 `24`。本仓库没有 `.nvmrc`、Dockerfile 或 Railway 镜像固定。 [特性与依赖下限](2026-07-06-node-engine-floor.zh.md) 仍要求 22 线至少为 22.19，并与 Node 23 不相交；本范围满足该下限。`scripts/ci-workflow.spec.ts` 拒绝低于这些下限的具体 `actions/setup-node` 版本。

## 曾考虑的替代方案

- **`^22.23.4 || >=24.22.1`。** 否决：semver 把 `>=24.22.1` 视为之后的每一个主版本，因此 Node 25（无修复）与 Node 26.0.0–26.12.0（仍有漏洞）仍然匹配。
- **保留 Node 24.9 兼容性固定。** 否决：24.9 落在 24.0–24.11.1 内，这些版本报告主版本 24 却仍携带 v1 loader，并且低于 24.22.1。主版本 24 上的那一代 loader 已在支持范围之外。Node 22 下限仍会执行 v1 loader API，主要任务浮动的 `24` 则已超过 24.12 与 Brotli 修复。
- **浮动 `22` 而非固定 `22.23.4`。** 否决：浮动主版本会不再验证所声明的下限。[特性下限说明](2026-07-06-node-engine-floor.zh.md) 否决了同一种替换。

## 后果

- 遵守 `engines` 的安装器会拒绝受影响的 Node。本仓库没有设置 `engine-strict`，因此非严格安装仍可能运行；该范围是对外宣传的支持线。
- CI 不再提供 Node 22.19 或 Node 24.9。被误标的 24.0–24.11.1 loader 位于支持范围之外。
- `@types/node` 保持在 22.x 线。安全下限不引入仅 Node 24 才有的 API。
