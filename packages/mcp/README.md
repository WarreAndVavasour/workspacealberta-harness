# MCP — Model Context Protocol

English | [中文](README.zh.md)

## Summary

The packages in this group attach external MCP servers so their tools are available under stable server-qualified names. Configure a server in a composition or manage user-owned servers in Web Settings → Connections. Only MCP tools are bridged; resources and prompts are not supported.
